# 部屋一覧のグリッド / リスト表示切り替え

**実装時間**: 約30分（2026-08-20）

## 概要

部屋一覧の表示方法を「グリッド（カード）」と「リスト（行）」から選べるようにした。

- **デスクトップ（md 以上）**: 絞り込みセレクトの右側に切り替えボタンを設置。選択は `localStorage`（`roomListViewMode`）に保存され、次回以降も維持される
- **モバイル（md 未満）**: 切り替えボタンは出さず、常に行表示。YouTube アプリの検索結果のような「左にゲームアイコン、中央に部屋名・メタ情報・説明、右端に人数バッジ」の全幅タップ可能な行にした

## 実装のポイント

### 表示の出し分けは CSS ブレークポイントに委ねる

JS の resize 監視は使わず、2 つのコンテナを常にレンダリングして Tailwind のクラスで出し分けた。

- グリッドコンテナ: 静的 `hidden` + `:class="viewMode === 'grid' ? 'md:grid' : ''"` → グリッド選択時の md 以上でのみ表示
- 行コンテナ: `:class="viewMode === 'grid' ? 'md:hidden' : ''"` → モバイルは常時表示、md 以上はリスト選択時のみ表示

1 ページ最大 20 件なので DOM の二重レンダリングは許容範囲。

### 行はボタンを置かず全体をタップ対象に

YouTube 風の UI に合わせて、行の右端にボタンを並べる代わりに行全体をクリック / タップ対象にした。`handleRowClick(room)` はカードのボタンと同じ分岐（参加済み → 入室、未認証 → ログイン案内モーダル、空きあり → 参加モーダル（ホスト中チェック込みの既存 `openModal` を再利用））。参加不可（closed / 満員）の行は `opacity-60` でタップ無効。

アクセシビリティ対応として `role="button"` / `tabindex`（タップ不可の行は -1）/ `aria-label` / Enter キー対応を付けた。

### その他

- 行コンテナはモバイルで `-mx-4` によりエッジトゥエッジ表示、sm 以上では枠付きの角丸カードに戻す
- ゲームアイコンは既存の `.game-icon`（48×48 固定、ゲームコード入り）をそのまま行の「サムネイル」として使用
- 旧グリッドの `grid-cols-1`（モバイル用 1 カラム）と `justify-items-center` はモバイルが行表示になったため削除
