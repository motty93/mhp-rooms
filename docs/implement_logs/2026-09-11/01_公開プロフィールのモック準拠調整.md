# 公開プロフィールのモック準拠調整

- 実装日: 2026-09-11
- 所要時間: 13:05 〜 13:17

## 概要

Issue #218 / PR #219 で実装済みの公開プロフィール画面を、基準にした `docs/mockups/user_profile.html` と突き合わせ、残っていた差分を実装へ反映した。モックのヘッダーは仮置きのため対象外とし、本物のヘッダーには手を入れていない。

## 変更内容

1. ユーザー名を `@username` 形式で表示（ハンター一覧・自分のプロフィールと統一）。表示名未設定時は見出しが `@username` になるため、ユーザー名行は出さない
2. 「その他」ボタンを 44px のアイコンボタンに変更（`aria-label="その他の操作"`、通報メニューはそのまま）
3. アクティビティタブに件数バッジを追加（直近 14 日分を `CountUserActivities` で取得。`UserProfileData.ActivityCount`）
4. アクティビティ一覧をモックの区切り線リストに変更（アイコンマーク + タイトル / 説明 / 時刻）。既存の `IconColor` はアイコン色として維持
5. タブの文字サイズをモバイルで 14px にし、420px 以下では件数バッジを非表示（モックと同じ。360px でタブが 2 行に折り返す問題を解消）
6. 9 月の更新情報に「公開プロフィール画面のレイアウトを改善」を追記し `summary` を更新。`updated` はリリース時に更新する

## 注意した点

- フォロー操作後の htmx 部分更新（`profile_card_content`）に必要なデータは変えていない。件数バッジはカード外なので影響しない
- 表示名未設定ユーザーで `@@username` にならないことをテストで担保
- 環境別ロジックは追加していない
- 変更したテンプレートは Prettier（go-template プラグイン）で整形済み
