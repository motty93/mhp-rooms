# リリース時の更新情報確認手順

## 作業時間

約20分

## 概要

更新情報の日時が古いまま本番リリースされると、一部のユーザーに新着のお知らせとして表示されない問題を防ぐため、
リリース前の確認手順を整備しました。今回の更新情報についても、`updated` を実際のリリース日時へ修正しました。

## 対応内容

- `docs/deploy.md` に、更新情報の本文、`summary`、`updated` と生成結果を確認する必須手順を追加
- `updated` と `user_notification_states.info_read_at` による未読判定の関係を明記
- ステージングへのマージ後に不備が判明した場合の復旧手順を追加
- `AGENTS.md` と `CLAUDE.md` からデプロイ手順を参照するルールを追加
- `CLAUDE.md` の実装ログ日付に関する固定年の指定を、実際の実装日を使うルールへ修正
- 2026年8月の更新情報の `updated` を本リリース日時へ修正

## 動作確認

- `make generate-info`
- `static/generated/info/articles.json` における対象記事の `updated` 確認
- `git diff --check`
