# ハンター一覧

## 概要

公開ハンターを検索・並び替えできる `/users` を追加しました。

## 設計判断

- 活動情報と部屋作成数は相関サブクエリで取得し、カードごとのN+1問い合わせを避けています。
- 検索は通常GETでも動作し、HTMX利用時だけ結果領域とURLを更新します。
- 公開DTOにはメールアドレスやSupabase認証IDを含めず、プロフィール導線には主キーのユーザーIDを使用しています。
