# 最近のうごき

## 概要

部屋一覧へ公開対象の最近の活動を遅延表示しました。

## 設計判断

- 公開活動は部屋作成・部屋参加・ユーザー登録だけにモデル定数で限定しました。
- 部屋一覧本体の初期描画を妨げないよう、HTMX でフィードを遅延取得します。
- 公開DTOにはメールアドレスやSupabase認証IDを含めず、プロフィール導線には主キーのユーザーIDを使用しています。
- 活動横断取得に合わせ、PostgreSQLとTursoの両方へ活動種別・作成日時の複合インデックスを追加しました。
