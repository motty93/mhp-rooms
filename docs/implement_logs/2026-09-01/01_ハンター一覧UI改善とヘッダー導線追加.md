# ハンター一覧UI改善とヘッダー導線追加

- 実装時間: 約20分（2026-09-01 10:05頃 〜 10:24）

## 実装した機能の概要

ユーザーからの指摘3点に対応した。

1. **検索ボタンが縦に大きく表示される問題の修正**
   - `templates/pages/users.tmpl` の検索フォーム右カラム（`flex flex-col sm:flex-row`）に `items-end` がなく、flex の既定値 `align-items: stretch` によりボタンが隣の「並び替え」ブロック（ラベル + セレクト ≒ 68px）と同じ高さまで引き伸ばされていた
   - 並び替えセレクトの移設（下記2）に伴いフォームを `検索入力 + ボタン` のみのグリッド（`sm:grid-cols-[1fr_auto] sm:items-end`）に整理し、stretch の原因ごと解消した

2. **並び替えセレクトの別枠化と即時反映**
   - 並び替えは「結果リストに対する操作」のため、検索フォームから結果リスト右上（`templates/components/hunter_list.tmpl` の件数表示行）へ移設
   - セレクトに `hx-get="/users"` + `hx-trigger="change"` を付与し、選択した瞬間に一覧を更新するようにした
   - 相互のパラメータ保持のため、セレクトには `hx-include="#hunter-search"`（検索キーワードを同送）、検索フォームには `hx-include="#hunter-sort"`（並び順を同送）を付与
   - URL 同期はハンドラー側の既存 `HX-Push-Url` レスポンスヘッダー（`internal/handlers/user.go` の `List`）がそのまま機能するため変更不要

3. **ヘッダーに「部屋一覧」リンクを追加**
   - デスクトップヘッダーの常設ナビが「ハンターを探す」のみで、部屋一覧への直接導線がなかった
   - `templates/components/header.tmpl` の StaticPage 側・非 StaticPage 側の両方で、「ハンターを探す」の左に「部屋一覧」リンクを追加
   - 非 StaticPage 側は `Title "部屋一覧"` で `aria-current="page"` とハイライトを付与（既存の「ハンターを探す」と同じパターン）
   - モバイルはハンバーガーメニュー内に既存リンクがあるため変更なし（ヘッダー表示仕様も維持）

## 特に注意した点・工夫した点

- 並び替えセレクトは `#hunter-results`（`hx-swap="outerHTML"` の置換対象）内に置いた。並び順の選択状態が `HunterListData.Sort` から常に再描画されるため、状態同期の追加実装が不要
- セレクトは検索0件時にも表示される位置（`if .Hunters` の外）に置いた。0件時にセレクトが消えると検索フォームの `hx-include="#hunter-sort"` が参照先を失うため
- JS なし環境のフォールバック（プレーンな GET submit）では sort がフォーム外になるためデフォルト順に戻るが、実害が小さいため hidden input の二重管理はせず KISS を優先
- StaticPage 側ヘッダーには `aria-current` 分岐を付けていない（StaticPage で Title が「部屋一覧」になるページは存在しないため）
